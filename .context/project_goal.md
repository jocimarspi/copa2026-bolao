# Objetivo e Propósito do Projeto

O **Bolão Copa 2026 - DB1 Group** é um aplicativo de palpites interno projetado exclusivamente para os colaboradores do grupo **DB1 Group** para a Copa do Mundo FIFA de 2026 (sediada nos EUA, Canadá e México).

## Propósito do Projeto
- **Engajamento Interno**: Promover a integração, socialização e diversão entre colaboradores de diferentes equipes, ecossistemas e unidades de negócio de forma interativa.
- **Competição Saudável**: Estimular a disputa amigável por meio de rankings de pontuação individuais e coletivos (por Unidade de Negócio).
- **Demonstração Tecnológica**: Servir como um projeto moderno construído com boas práticas de desenvolvimento web (React + TypeScript + Firebase).
