# Glossário do Projeto

Este glossário descreve a terminologia usada em toda a documentação e código do Bolão.

- **Kickoff**: Horário oficial de início da partida (armazenado no formato ISO UTC no banco de dados).
- **Palpite / Prediction**: Placar de gols (mandante × visitante) previsto pelo colaborador para uma determinada partida.
- **Unidade de Negócio / Business Unit (BU)**: Divisões e empresas do grupo DB1 (ex: Koncili, Anymarket, Predize, Winnerbox, holding).
- **Ecossistema**: Grupo maior que reúne unidades de negócio correlatas (ex: E-COMMERCE, TECHFIN, Holding, Christian Tech, DB1 Labs).
- **Partida de Teste**: Jogos fictícios utilizados para testes do sistema. Eles aparecem sinalizados na interface e suas pontuações não influenciam os rankings oficiais.
- **Mata-mata**: Fases eliminatórias da Copa do Mundo (Oitavas, Quartas, Semifinais, Final) gerenciadas pelos administradores.
- **SSO (Single Sign-On)**: Login único integrado do DB1 Group via provedor Microsoft Entra ID.
- **Cloud Functions**: Funções executadas de forma serverless no ambiente Firebase para realizar tarefas de sincronização e processamento pesado em segundo plano.
- **Bootstrap Admins**: Administradores definidos de forma estática no código do projeto para garantir o primeiro acesso administrativo e configuração do banco.
